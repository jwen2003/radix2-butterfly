# Radix-2 Butterfly MVP：定点规格

## 1. 文档目的

本文档冻结 Radix-2 Butterfly MVP 的定点数据格式、位宽传播、舍入、饱和及饱和标志行为。本文档是 Python 位精确参考模型、SystemVerilog RTL 和测试平台共同遵守的数值契约。

本文档不决定流水级划分、寄存器位置、评测包装层或目标工艺实现。不同微架构版本必须遵守同一份定点规格；除延迟外，对相同输入产生逐位一致的输出和饱和标志。协议细节见 `03_microarchitecture.md`，验证方法与覆盖范围见 `04_verification_plan.md`，实现结果见 `05_synthesis_and_ppa_analysis.md`。

## 2. 数学定义

MVP 实现 DIF Radix-2 复数 Butterfly：

```math
Y_0=A+B
```

```math
Y_1=(A-B)W
```

展开为实数运算：

```math
Y_{0,\mathrm{re}}=A_{\mathrm{re}}+B_{\mathrm{re}}
```

```math
Y_{0,\mathrm{im}}=A_{\mathrm{im}}+B_{\mathrm{im}}
```

```math
D_{\mathrm{re}}=A_{\mathrm{re}}-B_{\mathrm{re}}
```

```math
D_{\mathrm{im}}=A_{\mathrm{im}}-B_{\mathrm{im}}
```

```math
P_{\mathrm{re}}=D_{\mathrm{re}}W_{\mathrm{re}}-D_{\mathrm{im}}W_{\mathrm{im}}
```

```math
P_{\mathrm{im}}=D_{\mathrm{re}}W_{\mathrm{im}}+D_{\mathrm{im}}W_{\mathrm{re}}
```

最终输出为量化后的 `Y_0` 和 `P`。本文档后续以 `P_re`、`P_im` 表示舍入和饱和前的宽位复数乘法结果。

## 3. Q 格式约定

本文档采用以下命名约定：

> `Qm.n` 中，`m` 包含符号位及整数侧其余位，`n` 表示小数位数，总位宽为 `m+n`。

因此，16 位 Q1.15 的整数编码 `X_int` 与实际数值 `X` 的关系为：

```math
X=X_{\mathrm{int}}2^{-15}
```

其整数编码范围为：

```math
-32768\le X_{\mathrm{int}}\le32767
```

对应实际数值范围为：

```math
-1\le X\le1-2^{-15}
```

物理比特中不保存小数点。Q 格式只是对二进制补码比特串的数值解释。扩展整数侧位宽不会移动相对于最低有效位的小数点，也不会改变量化步长。

## 4. 输入与输出格式

所有实部和虚部均为独立的有符号二进制补码信号。

| 信号 | 位宽 | 格式 | 量化步长 | 数值范围 |
|---|---:|---|---:|---|
| `a_re`, `a_im` | 16 | Q1.15 | `2^-15` | `[-1, 1 - 2^-15]` |
| `b_re`, `b_im` | 16 | Q1.15 | `2^-15` | `[-1, 1 - 2^-15]` |
| `w_re`, `w_im` | 16 | Q1.15 | `2^-15` | `[-1, 1 - 2^-15]` |
| `y0_re`, `y0_im` | 16 | Q1.15 | `2^-15` | `[-1, 1 - 2^-15]` |
| `y1_re`, `y1_im` | 16 | Q1.15 | `2^-15` | `[-1, 1 - 2^-15]` |

### 4.1 旋转因子输入约束

数据通路接受任意合法的 16 位 Q1.15 复数 `W`，不在硬件中检查：

```math
|W|=1
```

正常 FFT 测试使用由单位圆旋转因子量化得到的系数；鲁棒性和边界测试可以使用其他合法 Q1.15 编码。

Q1.15 可以精确表示 `-1`，但不能精确表示 `+1`。因此，量化后的正常旋转因子不一定严格满足单位模。位宽安全性不得依赖 `W` 严格位于单位圆上。

## 5. 位宽传播

### 5.1 加减结果

两个 16 位有符号数的完整加减结果一般需要 17 位。输入分量具有 15 个小数位，因此扩位后的加减结果为 17 位 Q2.15。

对于和：

```math
S=A+B
```

整数编码的完整范围为：

```math
-65536\le S_{\mathrm{int}}\le65534
```

对于差：

```math
D=A-B
```

整数编码的完整范围为：

```math
-65535\le D_{\mathrm{int}}\le65535
```

两者的量化步长仍为 `2^-15`。扩位增加动态范围，但不增加小数精度。

### 5.2 单个实数乘积

`D` 为 17 位 Q2.15，`W` 为 16 位 Q1.15。完整整数乘积使用：

```math
17+16=33\ \text{bit}
```

小数位数为：

```math
15+15=30
```

因此，每个单独的实数乘积保存为 33 位 Q3.30，其整数编码与实际数值的关系为：

```math
P=P_{\mathrm{int}}2^{-30}
```

四个单独乘积为：

```math
M_0=D_{\mathrm{re}}W_{\mathrm{re}}
```

```math
M_1=D_{\mathrm{im}}W_{\mathrm{im}}
```

```math
M_2=D_{\mathrm{re}}W_{\mathrm{im}}
```

```math
M_3=D_{\mathrm{im}}W_{\mathrm{re}}
```

### 5.3 复数乘加结果

一般而言，两个任意 33 位有符号数相加或相减需要 34 位。但本设计中的乘积受输入范围约束，不会覆盖任意 33 位数。

差值满足：

```math
|D_{\mathrm{int}}|\le65535
```

旋转因子分量满足：

```math
|W_{\mathrm{int}}|\le32768
```

单个实数乘积的最大绝对值不超过：

```math
65535\times32768=2147450880
```

两个乘积相加或相减的最大绝对值不超过：

```math
2\times2147450880=4294901760
```

33 位二进制补码范围为：

```math
-4294967296\le x\le4294967295
```

因此，在本文档规定的输入范围内，数学结果事实上落在 33 位有符号编码范围内。但 RTL 不依赖这一范围证明提前缩窄，而是保留通用加减规则产生的完整 34 位结果。

两个 33 位乘积必须先显式符号扩展到 34 位，再在 34 位中完成加减。`P_re` 和 `P_im` 此后保持为 34 位 Q4.30，直接进入舍入与饱和路径，不在量化前缩回 33 位。这样可以避免不安全缩窄，也使位宽规则不依赖特定输入约束。

### 5.4 位宽传播汇总

| 运算节点 | 位宽 | 格式 | 实际整数编码范围或约束 |
|---|---:|---|---|
| 输入分量 `A,B,W` | 16 | Q1.15 | `[-32768,32767]` |
| `S=A+B` | 17 | Q2.15 | `[-65536,65534]` |
| `D=A-B` | 17 | Q2.15 | `[-65535,65535]` |
| 单个 `D × W` | 33 | Q3.30 | 受 `D` 与 `W` 的实际范围约束 |
| `P_re,P_im` | 34 | Q4.30 | 由两个 33 位乘积显式扩展后加减 |
| 最终输出分量 | 16 | Q1.15 | `[-32768,32767]` |

## 6. 输出量化策略

最终四个输出分量均为 16 位 Q1.15。统一采用以下规则：

- 舍入模式：round-to-nearest, ties-to-even，即舍入到最接近值，恰好居中时取最低保留位为 0 的结果；
- 溢出模式：饱和，不允许二进制补码回绕；
- 处理顺序：先完成所需舍入，再检查范围，最后饱和。

### 6.1 `Y_0` 的量化

`Y_0=A+B` 的宽位结果为 17 位 Q2.15，与目标 Q1.15 具有相同的 15 个小数位。因此，`Y_0` 不需要删除小数位，也不进行舍入。

对每个分量分别执行：

```math
Q_{Y_0}=S_{\mathrm{int}}
```

```math
Y_{0,\mathrm{int}}=
\begin{cases}
32767, & Q_{Y_0}>32767\\
-32768, & Q_{Y_0}<-32768\\
Q_{Y_0}, & \text{其他情况}
\end{cases}
```

### 6.2 `Y_1` 的 ties-to-even 舍入

`P` 为 34 位 Q4.30，目标输出为 Q1.15，因此必须删除 15 个小数位。数学定义为：

```math
Q_{Y_1}=\operatorname{RNE}\left(\frac{P_{\mathrm{int}}}{2^{15}}\right)
```

其中 `RNE` 表示 round-to-nearest, ties-to-even。

为使正数和负数具有对称且无歧义的行为，本文用绝对值给出数学定义。参考模型可以直接按此定义实现；RTL 也可以采用与之逐位等价的二进制补码 `guard/sticky/kept_lsb` 实现。令：

```math
M=|P_{\mathrm{int}}|
```

```math
Q_0=\left\lfloor\frac{M}{2^{15}}\right\rfloor
```

```math
R=M\bmod 2^{15}
```

进位条件为：

```math
I=(R>2^{14})\lor(R=2^{14}\land Q_0\text{ 为奇数})
```

舍入后的有符号整数为：

```math
Q_{Y_1}=\operatorname{sign}(P_{\mathrm{int}})(Q_0+I)
```

当 `P_int=0` 时，`Q_Y_1=0`。

这一定义覆盖三种情况：

| 被删除部分 | 行为 |
|---|---|
| 小于半个目标 LSB | 保持 `Q_0` |
| 大于半个目标 LSB | 在绝对值方向进一位 |
| 恰好等于半个目标 LSB | 仅当 `Q_0` 为奇数时进位，使结果最低位为 0 |

若实现中显式计算绝对值，必须使用足够的扩展位宽，避免对最小二进制补码值直接取负造成再次溢出。当前 RTL 采用等价的二进制补码判定：`guard` 为被删除部分最高位，`sticky` 为其余被删除位的归约或，`kept_lsb` 为最低保留位，并在 `guard && (sticky || kept_lsb)` 时对算术右移得到的有符号基值加一。该规则同时覆盖正负数并实现 ties-to-even。

### 6.3 `Y_1` 的饱和

舍入完成后，对每个分量分别执行：

```math
Y_{1,\mathrm{int}}=
\begin{cases}
32767, & Q_{Y_1}>32767\\
-32768, & Q_{Y_1}<-32768\\
Q_{Y_1}, & \text{其他情况}
\end{cases}
```

必须先舍入再检查范围，因为舍入进位可能使原本靠近边界的宽位结果越界。

## 7. 饱和与回绕

饱和将越界结果钳制到最近的可表示边界：

```math
Y_{\max}=32767=1-2^{-15}
```

```math
Y_{\min}=-32768=-1
```

回绕则直接丢弃高位，并将保留的低 16 位重新解释为二进制补码。例如：

```math
32767+1\rightarrow-32768
```

回绕可能使轻微越界变成符号相反的大误差。MVP 明确禁止将直接截取低 16 位作为溢出处理方式。饱和不能消除过载，但能将其转化为有界、可检测的输出行为。

## 8. 饱和标志

模块输出四个与结果事务对齐的分量级饱和标志：

- `sat_y0_re`：`y0_re` 实际发生饱和时为 1；
- `sat_y0_im`：`y0_im` 实际发生饱和时为 1；
- `sat_y1_re`：`y1_re` 实际发生饱和时为 1；
- `sat_y1_im`：`y1_im` 实际发生饱和时为 1。

如上层只关心 `Y_0`、`Y_1` 或本事务是否发生任意饱和，可组合产生：

```math
\texttt{y0\_sat}=\texttt{sat\_y0\_re}\lor\texttt{sat\_y0\_im}
```

```math
\texttt{y1\_sat}=\texttt{sat\_y1\_re}\lor\texttt{sat\_y1\_im}
```

```math
\texttt{sat\_any}
=
\texttt{sat\_y0\_re}
\lor\texttt{sat\_y0\_im}
\lor\texttt{sat\_y1\_re}
\lor\texttt{sat\_y1\_im}
```

`y0_sat`、`y1_sat` 和 `sat_any` 均为派生兼容信息，不是本轮核心接口必须寄存的独立状态。

对于 `Y_1`，标志根据舍入后的 `Q_Y_1` 判断，与“先舍入、再范围检查、最后饱和”的处理顺序一致。

以下情况不得置位：

- 未经钳制便恰好等于 `0x7FFF`；
- 未经钳制便恰好等于 `0x8000`；
- 宽位 `Y_1` 略超 Q1.15 数值边界，但 ties-to-even 后仍得到范围内编码。

因此，饱和标志精确表示“本次输出在舍入后越界并被钳位”，而不是一般性的精度损失或接近边界。

无效事务期间，饱和标志的电平不承载语义；验证环境只在 `valid_out=1` 时采样输出数据和标志。具体无效周期驱动为 0 还是保持前值，由微架构文档统一规定。

## 10. 位精确一致性要求

Python 参考模型、V0 RTL、V1 RTL 和测试平台必须对所有有效事务满足：

- `y0_re`、`y0_im`、`y1_re`、`y1_im` 逐位一致；
- `sat_y0_re`、`sat_y0_im`、`sat_y1_re`、`sat_y1_im` 逐位一致；
- `y0_sat` 与 `y1_sat` 若出现在向量或测试平台中，必须分别等于对应两路分量标志的归约或；
- V0 为组合结果，V1 具有固定流水延迟；除结果出现时刻外，其有效事务的数值语义不得不同；
- 不允许使用语言默认取整、宿主机浮点舍入或隐式位宽规则代替本文档定义；
- 随机测试的期望值必须由整数位精确模型生成，浮点模型只用于辅助误差分析。

若 SystemVerilog 仿真、Python 行为或综合结果与本文档冲突，应先判断是实现错误还是规格缺陷；在完成分析并修改本文件前，不得静默改变 RTL 行为。

## 11. 必须覆盖的定点验证场景

至少覆盖以下场景：

1. 全零输入；
2. Q1.15 最小值 `0x8000` 与最大值 `0x7FFF`；
3. `A+B` 和 `A-B` 的正负极限；
4. `W=0`、可表示的接近 `+1`、精确 `-1` 及常用单位圆量化系数；
5. `Y_0` 恰好位于上下边界；
6. `Y_0` 刚好越过上下边界；
7. `Y_1` 被删除部分小于、等于和大于半个目标 LSB；
8. ties-to-even 的正数与负数、偶数与奇数最低保留位；
9. 舍入进位导致正向或负向越界；
10. 原始宽位结果略超输出数值边界，但舍入后仍处于编码范围内；
11. 实部不饱和而虚部饱和，以及相反情况，以验证四个分量级标志互不混淆；
12. 两个分量同时饱和；
13. 能够逼近复数乘加最大绝对值的输入组合；
14. 大规模随机输入，与整数位精确参考模型自动比较。

当前共同测试向量采用 17 列：6 个输入、4 个输出、2 个派生聚合标志、4 个分量级标志以及 1 个用例标签。V0 与 V1 测试平台读取同一数值字段；V1 额外验证固定延迟、气泡和复位语义。现有回归包含 1071 组向量并已由两版自检测试通过；该事实证明当前样本内的一致性，不等同于对全部 96 位输入空间的穷举证明。

## 12. 已冻结决定

- 输入 `A`、`B`、`W` 的每个分量均为 16 位 Q1.15；
- 输出 `Y_0`、`Y_1` 的每个分量均为 16 位 Q1.15；
- 加减中间结果为 17 位 Q2.15；
- 单个实数乘积为 33 位 Q3.30；
- 复数乘加先在显式扩展的 34 位中执行，并保持为 34 位 Q4.30 直到舍入与饱和；
- `Y_1` 使用 round-to-nearest, ties-to-even 从 30 个小数位缩减为 15 个小数位；
- `Y_0` 不需要小数位舍入；
- 所有输出采用饱和而非回绕；
- 处理顺序为先舍入、再范围检查、最后饱和；
- 输出四个分量级饱和标志 `sat_y0_re`、`sat_y0_im`、`sat_y1_re` 和 `sat_y1_im`；
- `W` 接受任意合法 Q1.15 编码，硬件不检查单位模。

## 13. 留给后续文档的事项

以下问题不属于定点数值规格，由微架构或验证文档决定：

- 流水级数和寄存器位置；
- V0 与 V1 的固定延迟；
- `valid` 流水和复位行为；
- 无效周期输出清零还是保持前值；
- 饱和与舍入逻辑是否位于独立模块；
- 综合工具如何将乘法映射到 FPGA DSP、ASIC 标准单元或其他目标资源；
- 多级 FFT 的级间缩放与整体信噪比策略。

多级 FFT 中频繁出现饱和，说明动态范围或级间缩放策略需要重新设计。饱和是明确的越界行为，不是完整 FFT 缩放策略的替代品。
